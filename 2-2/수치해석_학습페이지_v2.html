1. 방정식의 근

핵심 개념

f(x) = 0을 만족하는 x(근)를 반복 계산으로 근사합니다. 이분법은 구간을 반씩 줄여 가며 느리지만 안정적으로 수렴하고, 뉴턴법은 접선을 이용해 빠르게(2차 수렴) 수렴하지만 초기값과 미분값에 민감합니다.

반드시 기억할 공식

이분법
c = (a + b) / 2
오차 한계: |xn − x*| ≤ (b − a) / 2n
필요 반복 횟수: n ≥ log2( (b − a) / ε )
뉴턴법 (Newton–Raphson)
xn+1 = xn − f(xn) / f′(xn)
기호  a, b: 구간의 양 끝 / c: 중점 / x*: 참값(근) / n: 반복 횟수 / ε: 허용 오차 / f′: f의 도함수 / xn: n번째 근사값
이분법: f(a)·f(b) < 0 (구간 안에 근이 존재, f는 연속). 뉴턴법: f′(xn) ≠ 0 이고 초기값이 근 가까이에 있어야 수렴.

문제를 풀 때의 순서

  1. 이분법: f(a)·f(b) < 0 확인 → 중점 c 계산 → f(c) 부호가 같은 쪽 끝점을 c로 교체 → 허용 오차까지 반복.
  2. 뉴턴법: f′(x) 구하기 → 초기값 x0 정하기 → 공식에 대입해 x1, x2, … 계산 → 연속한 값의 차가 충분히 작아지면 종료.

예제

f(x) = x² − 2 의 양의 근(√2)을 뉴턴법으로 구하시오. 초기값 x0 = 1, 두 번 반복하여 x2를 구하고, 이분법으로 [1, 2]에서 오차 한계 0.01 이하가 되려면 최소 몇 번 반복해야 하는지도 구하시오.

① 조건 정리

f(x) = x² − 2,  f′(x) = 2x,  x0 = 1
뉴턴 공식: xn+1 = xn − (xn² − 2) / (2xn)

② 계산 과정

x1 = 1 − (1 − 2)/2 = 1 + 0.5 = 1.5
x2 = 1.5 − (2.25 − 2)/3 = 1.5 − 0.083333 = 1.416667
(참고: √2 = 1.414214 이므로 오차는 약 0.0024)

이분법: (2 − 1)/2n ≤ 0.01 → 2n ≥ 100
26 = 64 < 100,  27 = 128 ≥ 100 → n = 7
답: x2 ≈ 1.4167 (뉴턴법) / 이분법은 최소 7회 반복

자주 하는 실수

  • 이분법을 시작하기 전에 f(a)·f(b) < 0 인지 확인하지 않는다.
  • 반복 횟수 n을 구할 때 올림하지 않고 소수로 답한다 (예: 3.6회 → 4회).
  • 뉴턴법에서 f′(x)가 0에 가까운 점을 초기값으로 잡아 값이 크게 튄다.

2. 연립방정식 (가우스 소거법)

핵심 개념

연립일차방정식 Ax = b를 확대행렬로 쓴 뒤, 전진 소거로 상삼각 행렬을 만들고 후진 대입으로 마지막 변수부터 차례로 구합니다.

반드시 기억할 공식

전진 소거 (승수와 행 연산)
mik = aik / akk
(행 i) ← (행 i) − mik × (행 k)
후진 대입
xn = bn / ann
xi = ( bi − Σj=i+1n aijxj ) / aii   (i = n−1, …, 1)
기호  aij: i행 j열 계수 / akk: 피벗(기준 원소) / mik: 승수 / bi: 우변 상수 / n: 미지수의 개수
피벗 akk ≠ 0 이어야 합니다. 0이거나 매우 작으면 행을 교환(부분 피벗팅)합니다.

문제를 풀 때의 순서

  1. 방정식을 확대행렬 [A | b]로 씁니다.
  2. 첫 열의 피벗 아래를 승수를 곱해 0으로 만듭니다. 다음 열로 넘어가 상삼각 형태가 될 때까지 반복합니다.
  3. 맨 아래 식에서 xn을 구하고, 위로 올라가며 대입해 나머지 변수를 구합니다.
  4. 구한 해를 원래 식에 대입해 검산합니다.

예제

다음 연립방정식을 가우스 소거법으로 푸시오.

x + y + z = 6   …(R1)
2x − y + z = 3  …(R2)
x + 2y − z = 2  …(R3)

① 조건 정리

확대행렬 [A | b]:  (1, 1, 1 | 6), (2, −1, 1 | 3), (1, 2, −1 | 2)
첫 피벗 a11 = 1 ≠ 0

② 계산 과정

1단계 (x 소거): m21 = 2, m31 = 1
R2 − 2·R1 = (0, −3, −1 | −9)
R3 − 1·R1 = (0, 1, −2 | −4)

2단계 (y 소거): 피벗 −3, m32 = 1/(−3) = −1/3
R3 − (−1/3)·R2 = R3 + (1/3)·R2 = (0, 0, −7/3 | −7)

후진 대입
−(7/3)z = −7 → z = 3
−3y − z = −9 → −3y = −6 → y = 2
x + y + z = 6 → x = 6 − 2 − 3 = 1

검산: R2 → 2 − 2 + 3 = 3 ✓, R3 → 1 + 4 − 3 = 2 ✓
답: x = 1, y = 2, z = 3

자주 하는 실수

  • 행 연산을 계수에만 하고 우변 상수 b에는 빼먹는다.
  • 승수의 부호를 틀린다. 항상 (행 i) − m × (행 k) 형태로 계산한다.
  • 피벗이 0인데 그대로 나누거나, 행 교환 후 우변 상수를 같이 바꾸지 않는다.

3. 보간법

핵심 개념

주어진 점들 (xi, yi)을 지나는 함수를 만들어, 점 사이의 값을 추정합니다. 선형 보간은 두 점을 직선으로 잇고, 라그랑주 보간은 n+1개의 점을 지나는 n차 다항식을 만듭니다.

반드시 기억할 공식

선형 보간법
P1(x) = y0 + ( (y1 − y0) / (x1 − x0) ) · (x − x0)
라그랑주 보간법
Pn(x) = Σi=0n yi · Li(x)
Li(x) = Πj≠i (x − xj) / (xi − xj)
2점: L0 = (x−x1)/(x0−x1), L1 = (x−x0)/(x1−x0) 로 선형 보간과 같음
기호  (xi, yi): 주어진 자료점 / Pn: n차 보간 다항식 / Li(x): 라그랑주 기저 다항식 (Li(xi) = 1, 다른 점에서는 0) / Σ: 합, Π: 곱
xi가 모두 서로 달라야 합니다. 선형 보간은 x가 x0와 x1 사이일 때 가장 정확하며, 점이 n+1개이면 n차입니다. 점이 많다고 항상 정확한 것은 아닙니다(고차에서 진동 발생 가능).

문제를 풀 때의 순서

  1. 구하려는 x를 둘러싼 두 점(선형) 또는 사용할 모든 점(라그랑주)을 정합니다.
  2. 라그랑주는 각 i에 대해 Li(x)의 분자와 분모를 따로 계산합니다.
  3. yi · Li(x)를 모두 더합니다.
  4. 검산: L0 + L1 + … = 1 이 되는지 확인합니다.

예제

다음 표는 어떤 함수의 값이다. x = 3 에서의 값을 (a) 선형 보간(x = 2, 4 사용), (b) 세 점 전체를 사용한 라그랑주 보간으로 각각 구하시오.

x124
y1416

① 조건 정리

(a) (x0, y0) = (2, 4), (x1, y1) = (4, 16)
(b) 세 점 (1, 1), (2, 4), (4, 16) → 2차 다항식

② 계산 과정

(a) P1(3) = 4 + (16 − 4)/(4 − 2) · (3 − 2) = 4 + 6 = 10

(b)
L0(3) = (3−2)(3−4) / ((1−2)(1−4)) = (1)(−1)/(3) = −1/3
L1(3) = (3−1)(3−4) / ((2−1)(2−4)) = (2)(−1)/(−2) = 1
L2(3) = (3−1)(3−2) / ((4−1)(4−2)) = 2/6 = 1/3
검산: −1/3 + 1 + 1/3 = 1 ✓
P2(3) = 1·(−1/3) + 4·1 + 16·(1/3) = −1/3 + 4 + 16/3 = 9
답: (a) 10   (b) 9  (자료가 y = x²이므로 참값 9와 일치)

자주 하는 실수

  • 라그랑주 분모의 (xi − xj) 순서나 부호를 뒤집는다. 분자는 x − xj, 분모는 xi − xj.
  • 선형 보간을 두 점 밖(외삽)에 적용해 오차가 커진다.
  • 점이 n+1개일 때 n차인 것을 헷갈려 차수를 틀린다.

4. 수치미분·적분

핵심 개념

도함수는 가까운 점의 함수값 차이로, 정적분은 구간을 잘게 나눈 도형의 넓이 합으로 근사합니다. 간격 h가 작을수록 정확하며, 차수가 높은 공식일수록 같은 h에서 오차가 작습니다.

반드시 기억할 공식

전진 차분 (오차 O(h))
f′(x) ≈ ( f(x + h) − f(x) ) / h
중심 차분 (오차 O(h²))
f′(x) ≈ ( f(x + h) − f(x − h) ) / (2h)
사다리꼴 공식 (합성, 오차 O(h²))
T = (h/2) · [ f0 + 2(f1 + f2 + … + fn−1) + fn ]
Simpson 1/3 공식 (합성, 오차 O(h⁴))
S = (h/3) · [ f0 + 4(f1 + f3 + …) + 2(f2 + f4 + …) + fn ]
기호  h: 간격(적분에서는 h = (b − a)/n) / n: 소구간 개수 / fk = f(xk), xk = a + kh / O(hp): 오차가 hp에 비례
Simpson 1/3 공식은 소구간 개수 n이 짝수일 때만 사용합니다. 계수는 양 끝 1, 홀수 번째 4, 짝수 번째(내부) 2 입니다.

문제를 풀 때의 순서

  1. 미분: 주어진 h로 f(x±h) 값을 구한 뒤 공식에 대입합니다.
  2. 적분: h = (b−a)/n 계산 → 분점 xk와 fk 표 작성 → 공식의 계수를 맞춰 합산.
  3. Simpson에서는 n이 짝수인지 먼저 확인합니다.

예제

f(x) = x² 에 대하여 (a) x = 1, h = 0.5 일 때 전진 차분과 중심 차분으로 f′(1)을 구하고, (b) ∫02 x² dx 를 n = 2 로 사다리꼴 공식과 Simpson 1/3 공식을 이용해 근사하시오. (참값: 도함수 2, 적분 8/3 ≈ 2.6667)

① 조건 정리

(a) f(1) = 1, f(1.5) = 2.25, f(0.5) = 0.25
(b) a = 0, b = 2, n = 2 → h = 1,  x0 = 0, x1 = 1, x2 = 2
f0 = 0, f1 = 1, f2 = 4  (n = 2는 짝수 → Simpson 사용 가능)

② 계산 과정

(a)
전진 차분: (2.25 − 1)/0.5 = 2.5
중심 차분: (2.25 − 0.25)/(2 × 0.5) = 2.0

(b)
사다리꼴: T = (1/2)[0 + 2(1) + 4] = (1/2)(6) = 3
Simpson 1/3: S = (1/3)[0 + 4(1) + 4] = 8/3 ≈ 2.6667
답: (a) 전진 2.5, 중심 2.0  (b) 사다리꼴 3, Simpson 8/3 ≈ 2.6667

※ 중심 차분과 Simpson은 같은 조건에서 참값에 더 가깝습니다. (x²은 2차식이라 두 방법 모두 정확히 맞습니다.)

자주 하는 실수

  • Simpson 1/3 공식을 소구간 개수 n이 홀수일 때 그대로 적용한다.
  • 사다리꼴 공식에서 내부 항의 계수 2를 빼먹거나 h/2 대신 h를 곱한다.
  • 중심 차분의 분모를 h로 쓴다. 두 점 사이의 거리는 2h 이다.
