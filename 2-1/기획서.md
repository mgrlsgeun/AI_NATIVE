# 수치해석 시험 대비 학습 페이지

## 대상 사용자

- 수치해석 시험을 준비하는 대학생인 나.
- 시험 전에 자주 사용하는 공식과 대표 문제 풀이 방법을 빠르게 확인하고, 간단한 문제로 스스로 이해했는지 점검하고 싶을 때 사용합니다.
- 주로 노트북으로 사용하고, 이동 중에는 휴대폰으로도 내용을 확인합니다.

## 사용 목적

- 수치해석에서 자주 사용하는 핵심 공식과 풀이 순서를 한 페이지에서 빠르게 찾아봅니다.
- 주제별 핵심 개념을 확인한 뒤 간단한 연습 문제를 풀어 보며 시험 전에 내용을 복습합니다.
- 여러 강의 자료를 다시 찾아보지 않아도 필요한 공식과 풀이 흐름을 한곳에서 확인하는 것을 목적으로 합니다.

## 화면 구성과 동작

- 화면 맨 위에 `수치해석 시험 대비 학습 페이지` 제목과 간단한 사용 안내가 표시됩니다.
- 제목 아래에는 `방정식의 근`, `연립방정식`, `보간법`, `수치미분·적분` 등 주제별 이동 버튼이 있습니다.
- 주제 버튼을 누르면 해당 주제의 핵심 공식과 풀이 순서가 있는 위치로 이동합니다.
- 각 주제 영역에는 다음 내용이 순서대로 표시됩니다.
  - 핵심 개념
  - 반드시 기억할 공식
  - 문제를 풀 때의 순서
  - 간단한 예제 1개
- 공식은 다른 설명보다 눈에 잘 띄도록 별도 상자에 표시합니다.
- 각 예제에는 `풀이 보기` 버튼이 있으며, 처음에는 정답과 풀이를 숨깁니다.
- `풀이 보기`를 누르면 문제 해석 또는 조건 정리, 계산 과정, 최종 답이 나타납니다.
- 다시 버튼을 누르면 풀이를 접을 수 있습니다.
- 화면 아래에는 `맨 위로` 버튼을 두어 긴 페이지에서도 처음으로 쉽게 돌아갈 수 있게 합니다.
- 휴대폰에서는 내용이 화면 너비에 맞게 한 열로 표시되고 가로 스크롤 없이 읽을 수 있게 합니다.

## 필요한 자료

- 수치해석에서 자주 사용하는 공식과 개념 정리
- 다음 네 가지 주제의 대표 공식
  - 방정식의 근: 이분법, 뉴턴법
  - 연립방정식: 가우스 소거법
  - 보간법: 선형 보간법, 라그랑주 보간법
  - 수치미분·적분: 전진 차분, 중심 차분, 사다리꼴 공식, Simpson 1/3 공식
- 각 주제별 간단한 대표 예제 1개와 풀이
- 공식에 사용되는 기호의 의미와 적용 조건

## 필수 기능

1. 주제별 핵심 개념과 공식을 구분하여 보여 줍니다.
2. 상단의 주제 버튼을 누르면 해당 내용으로 이동합니다.
3. 각 주제마다 예제 문제와 `풀이 보기` 버튼을 제공합니다.
4. `풀이 보기` 버튼을 누르면 숨겨져 있던 풀이 과정과 답이 표시됩니다.
5. 휴대폰과 컴퓨터에서 모두 가로 스크롤 없이 주요 내용을 읽을 수 있습니다.
6. 외부 파일, 로그인, 서버, API 없이 HTML 파일 하나만 열어 사용할 수 있습니다.

## 완료 기준

- HTML 파일을 열었을 때 `방정식의 근`, `연립방정식`, `보간법`, `수치미분·적분` 네 주제가 모두 보입니다.
- 상단에서 `보간법` 버튼을 누르면 보간법 설명이 있는 위치로 이동합니다.
- 각 주제에서 핵심 공식과 공식에 사용되는 기호 설명을 확인할 수 있습니다.
- 각 주제에 예제 문제가 최소 1개씩 있어 총 4개 이상의 예제를 확인할 수 있습니다.
- 예제를 처음 볼 때 풀이와 정답은 보이지 않아야 합니다.
- `풀이 보기` 버튼을 누르면 해당 문제의 풀이 과정과 최종 답이 나타나고, 다시 누르면 풀이가 접혀야 합니다.
- 휴대폰 크기의 화면에서도 글자와 버튼이 화면 밖으로 잘리지 않고 가로로 밀지 않아도 내용을 읽을 수 있어야 합니다.
- 인터넷 연결을 끈 상태에서도 주요 내용과 버튼 기능을 사용할 수 있어야 합니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열려야 합니다.

## 추가 기능

- 주제별로 `중요` 표시를 눌러 시험 직전에 볼 공식만 모아 보는 기능
- 객관식 또는 숫자 입력 방식의 간단한 자가 점검 문제
- 사용자가 원하는 주제만 선택해 화면에 표시하는 필터 기능
- 틀린 문제 또는 다시 보고 싶은 문제를 저장하는 기능

## 한계 및 비목표

1. 이번 페이지에서는 수치해석 전체 범위를 다루지 않고, 시험 대비용 대표 주제 네 가지와 기본 공식만 제공합니다.
2. 학습 기록, 오답 기록, 사용자 계정 정보는 저장하지 않습니다. 페이지를 닫으면 사용 상태가 초기화될 수 있습니다.
3. 문제를 자동으로 생성하거나 AI가 질문에 답하는 챗봇 기능은 구현하지 않으며, 서버·API·로그인 기능도 사용하지 않습니다.

## 검증 방법

- 페이지에 표시된 공식과 예제 답을 수업 강의자료 또는 교재의 같은 공식·예제와 항목별로 대조합니다. 특히 공식의 부호, 분모, 지수, 적용 조건을 확인하고, 예제는 직접 계산한 결과와 페이지의 최종 답이 같은지 비교합니다. 하나라도 다르면 해당 부분을 수정한 뒤 다시 같은 절차로 확인합니다.
