# 미션 2 기록

- **사용한 AI 이름 / 주요 대화 캡처 파일명:** ChatGPT(GPT-6) / `미션2_원인분석_대화.png`, `미션2_수정요청_대화.png` *(캡처 파일명은 저장할 때 실제 이름으로 변경)*

- **좁혀서 적은 한 문장:** 영화 티어리스트에서 한 브라우저에 만든 계정과 영화 등급이 다른 브라우저에서는 보이지 않는 문제를 확인하고, 서버 없이 데이터를 옮길 방법을 추가한다.

- **좁히려고 해 본 것과 결과:** 처음에는 기획서와 HTML 전체를 비교해 달라고 요청했고, 계정 공유, 친구 검색, 영화 검색 등 여러 차이를 발견했다. 그중 **다른 브라우저에서 기존 계정과 티어리스트를 사용할 수 없는 문제**로 범위를 좁혔다. AI의 코드 분석에 따르면 같은 브라우저에서는 저장된 계정에 다시 접근할 수 있지만, 다른 브라우저에서는 계정을 찾지 못할 수 있다. *(브라우저에서 실제로 비교 시험한 결과는 아직 별도로 기록하지 않았다.)*

- **AI가 말한 원인과, 그 설명을 직접 확인한 결과:** AI는 계정과 티어리스트가 공용 서버가 아닌 브라우저의 `localStorage`에 저장되기 때문에 서로 다른 기기·브라우저에서 자동으로 공유되지 않는다고 설명했다. HTML에서 `localStorage.getItem()` 및 `localStorage.setItem()`을 이용하는 부분을 확인할 수 있었다. 다만 **실제 브라우저 2개를 사용한 재현 시험은 아직 완료하지 않아**, 설명이 실제 동작과 일치하는지 최종 확인이 필요하다. 확인 방법은 첫 번째 브라우저에서 계정을 만들고 영화 등급을 지정한 다음, 새로고침 시 유지되는지 확인하고 두 번째 브라우저에서 같은 닉네임이 기존 계정으로 인식되는지 비교하는 것이다.

| 파일명 | 고친 내용 | 다시 해 본 결과 |
|---|---|---|
| `영화_티어리스트_수정본.html` | 기존 디자인과 주요 기능은 유지하면서 **설정 → 내 계정 이동 코드 만들기**, **로그인 화면 → 다른 기기에서 계정 가져오기** 기능을 추가했다. 서버 없이 계정 및 영화 등급 기록을 수동으로 복사할 수 있도록 했다. | HTML 수정본이 만들어졌고 자바스크립트 문법 검사는 통과했다고 안내받았다. **실제 브라우저 간 계정 이동 테스트는 아직 수행하지 않았다.** 따라서 가져오기 성공 여부를 직접 확인한 후 결과를 추가해야 한다. |

- **(선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:** 서버 없이 HTML 파일 하나만 사용하는 경우, 서로 다른 사용자가 친구의 티어리스트를 실시간으로 검색·비교하려면 어떤 제약이 있는지 이야기하고 싶다. 현재 수정은 계정을 직접 복사하는 방식이지 자동 동기화가 아니기 때문이다.

> **제출 전 확인:** 두 브라우저에서 계정 생성·이동 코드 복사·가져오기·재로그인·영화 등급 유지 여부를 직접 시험하고, 위의 '다시 해 본 결과'를 관찰한 내용으로 바꾸기. 대화 캡처 파일명도 실제 저장한 이름으로 수정하기.
