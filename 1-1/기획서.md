# 영화 티어리스트 웹페이지 기획서

> 작성 기준: 사용자와의 요구사항 질의응답 및 최초 아이디어 메모. 사용자가 확정하지 않은 세부사항은 임의로 결정하지 않음.

## 1. 누가 쓰나

- 영화를 좋아하는 사용자와 친구들 등, 웹사이트에 접속하는 여러 사람이 이용한다.
- 누구나 인터넷으로 접속할 수 있고, PC와 휴대폰에서 사용할 수 있어야 한다.
- 사용자는 **중복되지 않는 닉네임과 비밀번호**로 자신의 계정을 이용한다. 이메일 가입은 요구되지 않았다.
- 비밀번호를 잊어버린 경우 **복구용 코드**로 재설정한다.
- 각 사용자는 **자신의 티어리스트 한 개**를 만들고 수정한다.
- 다른 사용자는 닉네임으로 검색하여 공개된 티어리스트를 조회하고 비교할 수 있다. 모든 사용자의 티어리스트는 닉네임 검색으로 조회 가능하도록 한다.

## 2. 무엇을 하려고

- 자신이 본 영화를 **S / A / B / C / D / F**의 여섯 등급으로 나누어 재미로 순위를 매긴다.
- 친구들이 각자 만든 영화 티어리스트를 서로 확인하고 비교한다.
- 동일 등급에 속한 영화 사이에는 별도의 순위를 매기지 않는다.
- 비교할 때 **두 사람의 티어리스트를 나란히 보는 화면**과 **영화별로 부여한 등급을 비교하는 화면**을 전환해 이용한다.
- 한 사람만 평가한 영화도 비교 결과에 포함하며, 다른 사람의 등급은 미평가로 표시한다.
- 완성한 티어리스트를 **PNG 이미지**로 저장할 수 있다.

## 3. 화면과 동작

### 3.1 시작·계정

- 시작 흐름: **닉네임 입력 → 내 티어리스트**.
- 계정 접근에는 닉네임과 비밀번호를 사용한다.
- 닉네임 중복은 허용하지 않는다.
- 복구용 코드를 이용한 비밀번호 재설정을 제공한다.

### 3.2 내 티어리스트

- 영화관 느낌의 **어두운 디자인**을 적용한다.
- 영화는 **포스터 이미지와 제목**을 함께 보여준다.
- 등급 영역: **S, A, B, C, D, F** (총 6단계).
- 영화를 **드래그 앤 드롭**하거나 **클릭해 등급을 선택**하는 두 가지 방식으로 분류한다.
- 등급이 지정되지 않은 영화는 **화면 아래 미분류 영화 목록**에 표시한다.
- 등급 내 영화의 개별 순위는 정하지 않는다.
- 티어리스트에 추가 가능한 영화 개수는 제한하지 않는다.
- 티어 변경 사항은 **즉시 자동 저장**하고 이후에도 수정할 수 있다.
- PC와 휴대폰에서 같은 계정으로 동일한 기록에 접근할 수 있어야 한다.
- 티어리스트를 PNG 파일로 저장하는 기능을 제공한다.

### 3.3 영화 찾기·추가

- 초기 영화 목록으로 **인기 영화 약 50개**를 제공한다.
- 사용자가 영화를 검색해 목록에 자유롭게 추가할 수 있다.
- 한국 영화와 해외 영화를 모두 검색할 수 있다.

### 3.4 친구 검색·비교

- **닉네임 검색**으로 다른 사용자를 찾는다.
- 다른 사용자의 티어리스트는 누구나 조회할 수 있다.
- 비교 화면은 다음 두 보기를 전환한다.
  1. 두 사용자의 티어리스트를 나란히 배치한 보기
  2. 영화별로 두 사용자가 매긴 등급을 대조하는 보기
- 한쪽만 평가한 영화도 표시하고, 평가하지 않은 쪽은 **미평가**로 나타낸다.

### 3.5 화면 대응

- PC와 모바일 화면에서 모두 사용할 수 있게 구성한다.
- 모바일에서도 영화 분류가 가능해야 한다(클릭하여 등급 선택 방식 포함).

## 4. 필요한 자료

- **TMDB 영화 데이터 API**: 영화 제목, 포스터, 영화 검색에 사용할 자료 출처.
- **인기 영화 약 50개**: 최초 제공할 영화 목록. 구체적인 선정 작품은 아직 미정.
- **최초 아이디어 메모에 나온 영화 8편**: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리. 이 8편을 초기 50편에 반드시 포함할지는 아직 확정되지 않음.
- **사용자 데이터**: 고유 닉네임, 계정 인증 정보, 복구용 코드 관련 정보, 사용자별 영화·등급 기록.
- **서버 측 저장 수단**: 자동 저장과 PC·모바일 간 동일 기록 접근 및 다른 사람의 조회를 지원하기 위한 저장 환경. 구체적인 서비스·기술은 미정.
- **인터넷 공개 배포 환경**: 누구나 웹사이트에 접속할 수 있어야 함. 구체적인 도메인·호스팅 서비스는 미정.

## 5. 완성 기준

다음 조건을 충족하면 요청한 **핵심 기능과 디자인**이 구현된 것으로 판단한다.

- [ ] 인터넷에 공개된 웹페이지에 PC와 모바일 모두 접속할 수 있다.
- [ ] 중복되지 않는 닉네임과 비밀번호로 계정을 만들고 다시 이용할 수 있다.
- [ ] 복구용 코드로 비밀번호를 재설정할 수 있다.
- [ ] 사용자마다 티어리스트 한 개를 보유한다.
- [ ] TMDB를 통해 한국·해외 영화를 검색하고 추가할 수 있다.
- [ ] 초기 화면에 인기 영화 약 50개가 제공된다.
- [ ] 영화 포스터와 제목을 함께 확인할 수 있다.
- [ ] S/A/B/C/D/F 등급에 드래그 또는 클릭으로 영화를 배치·변경할 수 있다.
- [ ] 미분류 영화가 티어리스트 아래에 표시된다.
- [ ] 영화 추가 개수에 별도의 제한을 두지 않는다.
- [ ] 티어 변경 시 데이터가 즉시 자동 저장되고, 새로고침하거나 다른 기기에서 접속해도 유지된다.
- [ ] 닉네임 검색으로 다른 사용자의 티어리스트를 조회할 수 있다.
- [ ] 나란히 비교 보기와 영화별 비교 보기를 전환할 수 있다.
- [ ] 한쪽만 평가한 영화도 비교되고 미평가 여부를 확인할 수 있다.
- [ ] 결과를 PNG 이미지로 저장할 수 있다.
- [ ] 영화관 느낌의 다크 테마가 PC·모바일 화면에서 사용 가능하게 적용된다.

### 아직 결정되지 않은 사항 (임의 확정하지 않음)

1. **초기 인기 영화 50편의 구체적인 목록**과 최초 메모의 영화 8편 포함 여부.
2. **닉네임·비밀번호의 세부 규칙**(길이, 허용 문자 등)과 복구 코드 발급·보관·재발급 절차.
3. **TMDB API 키 발급·관리 방법** 및 영화 검색의 정렬·필터·중복 작품 처리 세부 정책.
4. **기술 스택, 데이터베이스, 서버/호스팅, 도메인** 등 구체적인 구현·운영 수단.
5. **PNG 이미지의 출력 범위·형식**(미분류 목록 포함 여부, 긴 티어리스트의 이미지 처리 등).
6. **저장 실패·네트워크 끊김 상황에서의 처리** 및 계정 탈퇴·기록 삭제 방식.
7. **비교 대상이 없는 경우나 닉네임 검색 결과가 없는 경우의 화면 표현** 등 세부 예외 동작.

> 위 항목은 미정 사항이며, 이 기획서에서 특정 방식으로 확정하지 않았다. 개발 착수 시 필요한 항목부터 추가로 결정한다.
