# 민수 님께 드리는 피드백

잘된 점: 영화를 클릭한 뒤 S·A·B·C 등급 글자를 누르거나 드래그해서 옮길 수 있고, 한 영화가 여러 칸에 중복되지 않고 옮긴 칸에만 남도록 되어 있습니다. `처음으로`를 누르면 추가한 영화까지 없어지고 처음 영화 8개가 모두 미분류 상태로 돌아오는 점도 기획서와 맞았습니다.

고치면 좋을 점
1. 본 것: 기생충을 S칸으로 옮긴 뒤 페이지를 다시 열면 기생충이 다시 미분류로 돌아온다.
   기준: 기획서의 “같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.”
   제안: 영화 목록과 각 영화의 등급을 브라우저 저장소에 저장하고, 페이지를 다시 열 때 저장된 상태를 불러오면 좋겠다.

2. 본 것: 제목 입력칸을 비운 채 `추가`를 누르면 제목이 없는 빈 영화 카드가 하나 생긴다.
   기준: 기획서에는 빈 제목을 막는다는 조건이 따로 없지만, 제목을 입력해 영화 카드를 추가하는 기능을 쓰는 과정에서 빈 카드가 생기면 무엇을 추가한 것인지 알 수 없다.
   제안: 제목을 공백까지 제거한 뒤 내용이 없으면 카드를 추가하지 않고 “영화 제목을 입력해 주세요” 같은 안내를 보여 주면 좋겠다.

3. 본 것: 화면 폭을 휴대폰 정도로 좁혀 보면 페이지 폭이 화면보다 크게 유지되어 오른쪽 내용이 잘린다.
   기준: 기획서의 “화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.”
   제안: 페이지 폭을 고정된 960px 대신 `max-width`와 `width: 100%`를 사용하도록 바꾸고, 좁은 화면에서는 버튼과 카드 영역이 화면 안에 들어오도록 반응형 스타일을 적용하면 좋겠다.

4. 본 것: 미분류 영화 목록이 모든 등급 아래에 있어서 아래쪽 영화 카드를 S나 A처럼 위쪽 등급으로 드래그할 때 긴 거리를 이동해야 한다.
   기준: 기획서에는 목록 위치에 대한 조건은 없지만, 실제로 영화를 여러 번 분류할 때 반복해서 위아래로 움직여야 해서 불편했다.
   제안: 선택한 카드는 등급 버튼으로 바로 이동할 수 있다는 점을 더 눈에 띄게 안내하거나, 좁은 화면에서는 등급 선택 버튼을 가까운 위치에 보여 주면 드래그를 길게 하지 않아도 사용할 수 있을 것 같다.
