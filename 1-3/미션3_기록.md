# 미션 3 기록 

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI: 저장 기능이 없어 파일을 다시 열면 모든 영화가 미분류로 돌아간다. | 기생충을 S칸으로 옮긴 뒤 다시 열면 초기 상태로 돌아가고 기생충도 미분류에 있다. | 반영 | 직접 확인한 결과가 맞고, 기획서에 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남아야 한다고 되어 있다. |
| AI: `처음으로`를 눌러도 직접 추가한 영화가 남는다. | `새영화`를 추가한 뒤 `처음으로`를 누르면 `새영화`는 사라지고 처음 영화 8개만 모두 미분류로 돌아온다. | 보류 | 직접 확인해 보니 AI의 설명과 다르다. 현재 동작이 기획서의 “처음 영화 목록과 배치로 돌아갑니다”에 맞는다. |
| AI: 빈 제목을 막지 않아 기획서를 어긴다. | 제목을 입력하지 않고 `추가`를 누르면 제목 없는 빈 카드가 생긴다. | 반영 | 빈 카드가 생기는 현상 자체는 실제로 확인된다. 다만 기획서에 “빈 제목을 막는다”는 조건은 없으므로 기획서를 어겼다는 AI의 설명은 정확하지 않다. 그래도 실제 사용 시 불편하므로 빈 제목은 추가되지 않게 하는 것이 좋다. |
| 동료: 휴대폰으로 열어 보니 불편했다. | 화면 폭을 휴대폰 정도로 좁히면 페이지가 화면보다 넓게 유지되고 오른쪽 일부가 잘린다. | 반영 | 기획서에 화면 폭이 좁아져도 오른쪽이 잘리지 않아야 한다는 완성 기준이 있으므로 수정할 이유가 분명하다. |
| 동료: 카드 옮기는 게 처음에는 헷갈렸다. | 카드 선택 후 등급 글자를 누르는 방식과 드래그 방식이 모두 동작하지만, “헷갈렸다”가 어느 부분을 뜻하는지는 이 의견만으로 특정하기 어렵다. | 되묻기 | “카드를 선택하는 방법, 등급 글자를 누르는 방법, 드래그하는 방법 중 어떤 부분이 가장 헷갈렸나요?”라고 물어보고 싶다. |
| 동료: 미분류 영화가 맨 아래라 S칸까지 드래그하기 불편하고, 목록이 위나 옆에 있으면 좋겠다. | 아래의 미분류 카드에서 위쪽 S·A 등급까지 드래그하려면 화면을 위로 이동해야 해서 거리가 길다. 다만 카드를 클릭한 뒤 등급 글자를 누르는 방식으로는 드래그하지 않고 이동할 수 있다. | 반영 | 기획서의 필수 조건은 아니지만 실제 사용에서 반복 동작이 불편하다. 목록 위치를 꼭 옮기기보다는 클릭 이동 방식을 더 잘 보이게 하거나 등급 선택 UI를 가까이 두는 식으로 개선할 수 있다. |
| 동료: 카드 색이 칙칙하다. | 카드가 회색 계열로 표시되는 것은 확인되지만 기능 사용에는 문제가 없었다. | 보류 | 색이 칙칙하다는 평가는 취향에 가까우며 기획서에 카드 색에 대한 조건이 없다. |
| 동료: 영화 포스터 사진이 같이 나오면 더 보기 좋겠다. | 현재 카드는 제목만 표시되고 포스터는 없다. | 보류 | 기획서에는 포스터를 표시해야 한다는 조건이 없고, 외부 파일 없이 HTML 한 장으로 열려야 한다는 조건이 더 중요하다. 보기 좋은 정도의 취향 개선이라 필수 수정으로 보지 않았다. |
| 동료: C칸은 없어도 될 것 같다. | 현재 S·A·B·C 네 등급이 모두 있고 정상적으로 영화를 옮길 수 있다. | 보류 | 기획서에서 영화를 S·A·B·C 등급으로 나누는 것이 목적이라고 명시했으므로 C를 없애면 오히려 기획서와 달라진다. |

- 아무도 말하지 않았는데 내가 찾은 것: 동료가 “휴대폰에서 불편하다”고만 말했지만, 화면 폭을 좁혀 보니 `.page` 폭이 고정되어 있어 오른쪽 내용이 실제로 잘리는 구체적인 문제가 있었다. 기획서의 “화면 폭이 좁아져도 오른쪽이 잘리지 않는다”는 완성 기준을 충족하지 못한다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: AI가 “빈 제목을 막지 않아 기획서를 어긴다”고 말한 것처럼, 실제 문제는 맞더라도 그 근거가 기획서에 없는 경우 어떻게 표현해야 하는지 비교해 보고 싶다. 또한 “휴대폰에서 불편하다”처럼 넓은 의견을 실제 확인 가능한 문제로 좁히는 방법도 동료와 비교해 보고 싶다.
