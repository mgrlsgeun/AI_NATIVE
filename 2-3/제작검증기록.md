- **AI 검토자:** ChatGPT (GPT-6)
- **사용자 테스트 참여자:** 별도 실사용자 관찰 미실시 — 아래에 실제 테스트용 작업과 기록란 마련

## 2. 테스트 3건 — 테스트 절차 및 확인 범위

| 번호 | 실제로 수행할 작업 | 예상 결과 | 현재 확인된 사항 | 브라우저 실제 결과 |
|---|---|---|---|---|
| T-01 | 첫 화면을 읽고 ‘방정식의 근’을 클릭한 뒤 ‘풀이 보기’를 누름 | 이동 후 풀이가 표시되고 버튼은 ‘풀이 접기’로 바뀜 | 해당 메뉴와 버튼 및 이벤트 처리 코드가 있음 | **[직접 실행 후 기록]** |

### 별도 확인한 구조 검사

- v3, v4, v5 HTML에서 모두 **4개 주제 섹션**, JavaScript 데이터 기준 **8개 자가 점검 문제**가 확인됨.
- 세 버전의 JavaScript에 대해 `node --check` 구문 검사 결과가 모두 정상(종료 코드 0)이었음.
- v3: 처음 사용 안내 존재 / 검색 초기화 버튼 없음 / 자동 저장 코드 없음.
- v4: 안내와 검색 초기화 버튼 존재 / 자동 저장 코드 없음.
- v5: 안내, 검색 초기화 버튼, 자동 저장 코드 존재.
- **한계:** 위 검사는 브라우저에서 모든 기능이 동작함을 보증하지 않는다.

## 3. 수정 기록 3건

### 수정 1 — 첫 사용자에게 시작 순서 안내 (v2 → v3)

- **발견한 문제 / 테스트 내용:** 첫 화면을 열고 학습을 시작하려는 상황을 검토함. 여러 학습 도구와 영역이 있지만 어떤 작업을 먼저 해야 하는지 단계가 전면에 보이지 않음.
- **예상 결과:** 사용자가 별도 설명 없이 단원 선택부터 점검까지 순서를 파악함.
- **확인된 실제 상태:** v2 첫 화면에는 페이지 소개와 단원 이동 버튼이 있으나 별도의 3단계 시작 안내 블록은 없음.
- **수정 이유:** 첫 방문자가 기능을 탐색하는 데 시간을 쓰거나 학습 흐름을 놓칠 수 있기 때문.
- **AI에게 전달한 요청(작업 의도를 정리한 문장):** “첫 사용자가 설명을 듣지 않아도 학습 순서를 알 수 있도록 상단에 단원 선택 → 공식·예제 → 점검·복습 안내를 추가해 줘. 다른 기능은 유지하고 HTML 전체를 버전별로 저장해 줘.”
- **수정 파일:** `수치해석_학습페이지_v3.html`
- **수정 후 확인:** HTML에서 3단계 안내 문구와 네 단원이 확인됨. **브라우저에서 실제 사용자가 순서를 이해하는지는 미확인.**
- **기존 기능 재검사:** 단원 이동·풀이 보기·점검 문제는 요소와 처리 코드 존재 확인. 실제 클릭 테스트는 **[수행 후 결과 기록]**.

### 수정 2 — 검색에서 전체로 복귀하는 방법 명확화 (v3 → v4)

- **발견한 문제 / 테스트 내용:** 검색하거나 여러 주제를 선택한 다음 원래 목록을 다시 보고자 하는 사용 흐름을 검토함.
- **예상 결과:** 별도의 복잡한 조작 없이 전체 목록으로 돌아가고 표시 결과의 수를 알 수 있음.
- **확인된 실제 상태:** v3에는 검색과 필터가 있지만 별도의 ‘검색·선택 초기화’ 버튼이 없음.
- **수정 이유:** 검색어 삭제와 필터 해제를 각각 수행해야 하는 혼란을 줄이기 위해서.
- **AI에게 전달한 요청(작업 의도를 정리한 문장):** “검색과 단원 선택을 한 번에 해제하는 버튼을 추가하고, 현재 보이는 주제 수를 표시해 줘. 기존 검색·단원 이동·문제 풀이 기능은 유지해 줘.”
- **수정 파일:** `수치해석_학습페이지_v4.html`
- **수정 후 확인:** 초기화 버튼과 표시 주제 수 갱신 코드가 존재함. 실제 버튼 테스트는 **[수행 후 기록]**.
- **기존 기능 재검사:** 네 단원·8개 문제 데이터 유지 및 JS 구문 검사 통과. 브라우저 동작은 **미확인**.

### 수정 3 — 새로고침 후 학습 결과 유지 (v4 → v5)

- **발견한 문제 / 테스트 내용:** 문제를 풀고 중요 공식을 표시한 뒤 페이지를 새로고침하는 상황을 검토함.
- **예상 결과:** 사용자가 표시해 둔 중요 공식·정답 이력·오답 목록·체크리스트를 다시 볼 수 있음.
- **확인된 실제 상태:** v4에는 학습 상태를 브라우저에 저장하는 코드가 없어 새 페이지 로드 시 누적 기록이 유지되지 않음.
- **수정 이유:** 학습을 중단했다가 다시 돌아온 사용자가 중요 표시와 체크를 처음부터 반복해야 하는 불편을 줄이기 위해서.
- **AI에게 전달한 요청(작업 의도를 정리한 문장):** “학습 상태를 브라우저에 자동 저장하여 다시 열어도 복원되게 해 줘. 전체 기록 초기화 버튼을 추가하고, 기존 단원 검색과 문제 판정은 그대로 유지해 줘.”
- **수정 파일:** `수치해석_학습페이지_최종_v5.html`
- **수정 후 확인:** localStorage 저장·복원 처리 및 전체 초기화 확인창 코드가 존재함. 저장 정책에 따른 실제 동작은 **[동일 브라우저에서 실행 후 기록]**.
- **기존 기능 재검사:** 단원 4개, 문제 8개와 JS 구문 정상 확인. 클릭·새로고침 회귀 검사는 **미실시**.

## 4. 사용자 1명 피드백과 반영 내용

### 4.1 AI 검토 의견(실제 수집 완료)

- **검토자:** ChatGPT (GPT-6) — 사람을 대상으로 한 사용자 테스트가 아니라 AI의 화면·코드 검토.
- **검토 요청:** 학습 목적을 처음 접하는 이용자의 입장에서 시작 방법, 검색 후 복귀, 학습 기록 유지 방식의 불편을 점검.
- **피드백:** ① 처음 무엇부터 해야 할지 명확히 안내하면 좋음, ② 검색과 선택을 한 번에 초기화할 방법이 필요함, ③ 학습 상태가 새로고침 후 사라지면 반복 기록 부담이 생김.
- **반영 내용:** v3 시작 안내, v4 검색·선택 초기화, v5 학습 기록 자동 저장 및 초기화.
- **반영 결과:** 관련 UI 요소와 프로그램 처리 코드가 최종 HTML에 포함된 것을 확인. 실제 사용자 편의성 개선 효과는 별도 사용자 테스트가 필요함.

### 4.2 과제 요구사항인 **실제 사용자 1명 관찰** — 미완료

> 아래는 제출 전에 **실제 사람 1명에게 작업만 제시하고**, 설명 없이 진행하는 과정을 관찰해 채울 부분이다. AI 검토를 실제 사람의 관찰로 대체하지 않는다.

- **테스트 참여자:** [실제 참여자: 동료 A 등]
- **진행 일시 / 환경:** [날짜, PC/모바일, 브라우저]
- **요청할 작업(사용법 설명 금지):** “수치해석 페이지에서 뉴턴법을 찾아 공식에 중요 표시를 하고, 첫 번째 문제를 푼 뒤, 다시 볼 문제 목록과 체크리스트를 확인해 주세요.”
- **사용자의 행동과 질문:** [실제로 한 클릭 순서, 머뭇거린 부분, 직접 한 질문을 그대로 기록]
- **사용자에게 받은 피드백:** [실제 발언]
- **반영할 개선 사항 1건 이상:** [피드백 → 실제 반영 파일/위치]
- **수정 후 같은 작업 재검사 결과:** [예상/실제 결과]

**주의:** 현재 v3~v5 변경은 AI 검토 의견을 반영한 것으로, 실제 사람에게서 받은 피드백이 반영되었다고 기록할 수는 없다. 사람이 다른 의견을 주면 HTML과 이 문서를 추가 수정해야 한다.
