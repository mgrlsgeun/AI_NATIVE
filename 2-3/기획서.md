ㅈ# 수치해석 시험 대비 학습 페이지 — 최종 기획서

- **최종 산출물:** `수치해석_학습페이지_최종_v5.html`
- **작성 기준:** 2026-11-11 / 최종 v5 HTML 반영
- **페이지 형태:** HTML 한 파일로 실행하는 오프라인 학습 자료
- **제작 방식:** AI와 초안을 제작하고, 사용 편의성 개선안을 버전별로 반영

## 1. 페이지 제작 목적

수치해석 시험을 준비하는 학습자가 여러 단원에 흩어진 공식을 빠르게 찾아보고, 예제를 풀어 보며, 자가 점검과 오답 복습까지 하나의 화면에서 수행하도록 돕는다. 특히 처음 사용하는 사람도 별도의 설명 없이 학습을 시작할 수 있게 구성한다.

## 2. 대상 사용자와 이용 상황

- **주요 사용자:** 수치해석을 학습하거나 시험을 앞둔 학생
- **이용 상황:** 시험 전 핵심 공식 확인, 모르는 단원 검색, 예제 풀이 확인, 정답 자가 점검, 오답 재확인
- **이용 환경:** PC 또는 모바일의 일반 웹 브라우저. 별도 서버 설치 없이 HTML 파일을 직접 연다.

| 3 | **처음이라면 이렇게 사용하세요** | 단원 선택 → 공식·예제 확인 → 점검·복습 순서 이해 |
| 4 | 검색, 주제 필터 및 초기화 버튼 | 원하는 단원을 좁혀서 보고 전체 목록으로 복귀 |

## 4. 핵심 콘텐츠

1. **방정식의 근:** 이분법과 뉴턴법, 관련 공식과 예제
2. **연립방정식:** 가우스 소거법의 전진 소거·후진 대입
3. **보간법:** 선형 보간과 라그랑주 보간
4. **수치미분·적분:** 전진·중심 차분, 사다리꼴 및 Simpson 1/3 공식

각 단원에는 개념 설명, 공식, 예제의 ‘풀이 보기/접기’, 자가 점검 문제, 자주 하는 실수를 배치한다. 자가 점검 문제는 단원별 2문항, 전체 8문항이다.

## 6. 주요 화면별 사용 흐름

**사용 흐름 A — 처음 학습하는 경우:** HTML을 열어 첫 화면의 3단계 안내를 확인 → 공부할 단원 선택 → 공식 확인 → 예제를 스스로 풀고 풀이 확인 → 자가 점검 답안을 입력.

**사용 흐름 B — 틀린 문제 복습:** 문제에 오답 입력 → 오답 안내와 함께 ‘다시 볼 문제’에 등록 → 복습 목록에서 해당 문제로 이동 → 다시 계산하고 답 확인.

**사용 흐름 C — 시험 직전 복습:** 중요 공식을 표시 → 모음에서 확인 → 체크리스트 점검 → 종료 후 같은 브라우저에서 다시 열어 저장된 상태를 확인.

## 7. 구현 범위와 비목표

### 구현할 기능

- 단원 탐색·검색, 공식·예제·자가 점검, 중요 공식 및 오답 모음
- 학습 현황·체크리스트, 브라우저 안에서의 자동 저장 및 초기화
- 모바일에서도 읽을 수 있는 반응형 화면

### 비목표 3가지

1. **회원가입·로그인·서버 계정 동기화:** 브라우저 로컬 저장만 사용한다.
2. **범용 수치해석 계산기:** 사용자가 임의의 함수와 행렬을 넣어 계산해 주는 기능은 만들지 않는다.
3. **강의자료 자동 수집·업로드·AI 채점:** 강의자료 연결, 파일 업로드, 서술형 답안 평가를 제공하지 않는다.

### 추가 기능(현재 미구현)

- 단원별 문제 추가 및 난이도 선택
- 학습 기록 내보내기/가져오기 및 기기 간 동기화
- 풀이 과정 단계별 입력과 채점

## 8. 구현 제약 및 주의사항

- HTML 한 파일을 로컬에서 실행하며 외부 서버·라이브러리를 필수로 요구하지 않는다.
- 학습 기록은 `localStorage`에 저장하므로 같은 브라우저·동일한 파일 출처에서 다시 열 때 복원될 수 있다. 다른 기기나 브라우저까지 자동 동기화되지는 않는다. 브라우저 설정·비공개 모드·저장 공간 정책에 따라 저장이 제한될 수 있다.
- 예제 확인 현황은 ‘풀이 보기’를 처음 눌렀는지, 정답 현황은 해당 문제를 한 번 이상 맞혔는지를 누적 기록한다.
- 수치해석 공식과 계산 결과의 정확성은 강의자료·교재와 별도로 대조해야 한다.

## 9. 완료 기준과 검증 방법

**완료 기준:** (1) 네 개 단원이 보임, (2) 검색·필터·초기화가 정상 동작함, (3) 네 예제의 풀이 열기/접기가 가능함, (4) 여덟 문제의 답 판정과 복습 등록이 가능함, (5) 중요 공식·체크리스트·정답 기록이 저장·초기화됨, (6) 처음 사용하는 사람이 설명 없이 시작 순서를 알 수 있음.

**검증 방법 1가지 — 동일 작업 기반 사용 시나리오 테스트:** 로컬 HTML을 브라우저에서 열고 ‘뉴턴 검색 → 초기화 → 첫 번째 예제 풀이 보기 → 정답 입력(1.5) → 중요 공식 표시 → 체크 → 새로고침 → 기록 확인 → 전체 초기화’를 수행하여 각 단계의 예상 결과와 실제 화면을 비교한다. 수정 버전에서는 동일 시나리오를 반복하고, 이전에 동작하던 기능에도 문제가 없는지 확인한다.

> **검증 상태:** HTML/JavaScript 구조와 구문에 대한 기계적 검사는 수행했다. 실제 사용자 행동 관찰과 브라우저 조작 테스트는 `제작검증기록.md`에서 미실시 항목을 구분해 후속 확인하도록 기록한다.
